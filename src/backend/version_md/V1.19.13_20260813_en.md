## Version 1.19.13 Release Notes

### New Features

- [ NEW ] Global and scene reports now support configuring BKVision parameters, with parameter default values overridden by scene or system.
- [ NEW ] Audit user profile tools now display and export token exchange ratios and test-account status, with support for test-account search and filtering.

### Optimizations

- [ OPTIMIZATION ] The report scope selector now includes system views, making it easier to view reports by system.
- [ OPTIMIZATION ] Status labels across the SaaS are now consistently shown as “Enabled / Disabled”.
- [ OPTIMIZATION ] Disabled Edit actions for smart tools now explain the reason and direct users to adjust visibility ranges instead.

### Fixed

- [ FIXED ] Fixed BKVision time controls not displaying when a report is opened from a link.
- [ FIXED ] Fixed AI audit risk reports that could include model reasoning in the report body.
