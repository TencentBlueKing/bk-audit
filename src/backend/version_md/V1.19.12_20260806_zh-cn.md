## V1.19.12 版本更新日志

### 新增

- [ 新增 ] 审计用户画像工具支持配置数据范围，限制工具可查询和展示的数据
- [ 新增 ] 平台管理下全局报表支持按场景或系统授权，并可按授权范围覆盖参数默认值
- [ 新增 ] 审计风险删除改为软删除，支持删除操作审计和恢复

### 优化

- [ 优化 ] 优化系统采集状态的批量查询体验
- [ 优化 ] 优化风险标签展示样式，超出部分支持汇总展示和悬浮查看
- [ 优化 ] 平台管理菜单中的“资源管理”调整为“全局资源”，并统一全局报表、全局工具名称
- [ 优化 ] 全局报表、全局工具在平台管理下停用后，不再在场景配置中展示
- [ 优化 ] 全局工具列表调整为按名称正序排列

### 修复

- [ 修复 ] 修复 AI 能力基座 MCP 调用处理表单请求和异常请求体时可能失败的问题
- [ 修复 ] 修复编辑处理套餐时规则参数为空的问题
- [ 修复 ] 修复系统详情中日志上报权限判断错误的问题
- [ 修复 ] 修复系统标签下拉列表未过滤虚拟标签的问题
