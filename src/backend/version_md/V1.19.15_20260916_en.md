## Version 1.19.15 Release Notes

### New Features

- [ NEW ] Added a Global Strategies module under Platform Management. Strategies can contain multiple risk-detection rules and dispatch risks to different scenes through dispatch rules.
- [ NEW ] Refactored scene Audit Strategy configuration to separate global and scene strategies, with draft saving supported.
- [ NEW ] Added a “Pending My Confirmation” risk module, supporting confirmation-before-dispatch, marking risks as false positives, and batch processing.

### Optimizations

- [ OPTIMIZATION ] BKBase strategy APIs now retry failed requests up to three times by default, improving stability during strategy configuration and execution.
