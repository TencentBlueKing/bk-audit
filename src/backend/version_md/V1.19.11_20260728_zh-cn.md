## V1.19.11 版本更新日志

### 新增

- [ 新增 ] AI 基座能力建设：MCP 接口支持用户态鉴权和返回内容优化，并在登录审计后自动预热 Agent 用户态授权
- [ 新增 ] 审计策略配置支持个人授权结果表管理，可按业务查询并选择已授权的数据表

### 优化

- [ 优化 ] 优化工具广场搜索与列表状态保持，切换场景时自动清理筛选条件，从工具详情返回后保留列表位置
- [ 优化 ] 优化所有风险的搜索条件展示和联动体验，搜索标签更易理解，删除条件后立即刷新结果
- [ 优化 ] 优化风险处理入口，从列表进入风险详情时自动展开工单处理区域
- [ 优化 ] 优化工具、系统和存储列表的检索状态保持，进入详情或编辑后返回可延续当前筛选条件

### 修复

- [ 修复 ] 修复场景风险进入详情后返回到历史处理页面的问题
- [ 修复 ] 修复工具人员选择器无法粘贴离职人员的问题
- [ 修复 ] 修复审计策略配置中数据源为空时选择器不展示、默认条件异常的问题
