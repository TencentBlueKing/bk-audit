## V1.19.17 版本更新日志

### 新增

- [ 新增 ] 场景风险和所有风险列表支持跨页批量处理，可批量人工关单、转单、执行处理套餐、标记误报和解除误报；普通操作最多 500 条，处理套餐最多 100 条
- [ 新增 ] AI 助手支持对审计日志进行智能分析和数据统计，支持报告列表、查看、编辑、导出和重新生成

### 优化

- [ 优化 ] 场景风险列表支持智能搜索，优化搜索条件和时间标签的展示与交互
- [ 优化 ] 风险详情中的处理套餐执行状态支持自动刷新

### 修复

- [ 修复 ] 修复平台管理全局工具可见范围弹窗中默认值重复显示提示的问题
- [ 修复 ] 修复工具广场部分工具卡片图标缺失的问题
- [ 修复 ] 修复 API 工具切换参数前端类型时可能清空其他参数默认值，以及操作列显示溢出的问题
