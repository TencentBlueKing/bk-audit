## Version 1.19.11 Release Notes

### New Features

- [ NEW ] Enhanced the AI foundation: MCP APIs now support user-context authorization and improved responses, and Agent user-context authorization is automatically prewarmed after signing in to Audit.
- [ NEW ] Added management for personally authorized result tables in audit strategy configuration, with business-based lookup and selection of authorized tables.

### Optimizations

- [ OPTIMIZATION ] Improved Tool Square search and list-state retention: filters reset when switching scenes, and the list position is preserved after returning from tool details.
- [ OPTIMIZATION ] Improved search-condition display and interactions in All Risks; labels are clearer and results refresh immediately after a condition is removed.
- [ OPTIMIZATION ] Improved the risk handling entry point by automatically expanding ticket handling when entering risk details from a list.
- [ OPTIMIZATION ] Improved search-state retention in tool, system, and storage lists when returning from details or editing.

### Fixed

- [ FIXED ] Fixed an issue where returning from a Scene Risk detail page opened the historical handling page.
- [ FIXED ] Fixed the inability to paste inactive users into the tool person selector.
- [ FIXED ] Fixed missing data-source selectors and incorrect default conditions when no data sources are available in audit strategy configuration.
