## Version 1.19.16 Release Notes

### New Features

- [ NEW ] Added an AI Assistant with conversations isolated by space, supporting grouping, drag-and-drop sorting, search, renaming, and deletion.
- [ NEW ] The AI Assistant supports audit log searches using natural language or query conditions, with multi-turn refinement, preview export of the first 100 results, and asynchronous full export.
- [ NEW ] Audit User Profile tools now support restricting searchable account types by space (scene or system).

### Fixed

- [ FIXED ] Fixed empty hover tooltips for some extended fields in audit log search results.
