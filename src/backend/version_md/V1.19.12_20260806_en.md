## Version 1.19.12 Release Notes

### New Features

- [ NEW ] Audit user profile tools now support data-scope configuration, limiting the data available for querying and display.
- [ NEW ] Global reports in Platform Management can now be authorized for scenes or systems, with parameter default values overridden for each authorized scope.
- [ NEW ] Audit risks now use soft deletion, allowing deletion operations to be audited and restored.

### Optimizations

- [ OPTIMIZATION ] Improved bulk status lookups for system data collection.
- [ OPTIMIZATION ] Improved risk-tag display: excess tags are summarized and available on hover.
- [ OPTIMIZATION ] Renamed the Platform Management “Resource Management” menu to “Global Resources” and standardized the names of Global Reports and Global Tools.
- [ OPTIMIZATION ] Disabled global reports and tools are no longer displayed in Scene Configuration.
- [ OPTIMIZATION ] Global tools are now listed in ascending order by name.

### Fixed

- [ FIXED ] Fixed MCP calls in the AI foundation that could fail when handling form requests or malformed request bodies.
- [ FIXED ] Fixed empty rule parameters when editing a handling package.
- [ FIXED ] Fixed incorrect permission checks for log reporting in system details.
- [ FIXED ] Fixed virtual tags appearing in the system-tag dropdown list.
