## Version 1.19.18 Release Notes

### New Features

- [ NEW ] Audit strategies can configure BKSEC security tickets, select risk types by project, map ticket fields, preview tickets, send test tickets to designated recipients, and filter strategies by ticketing enablement.
- [ NEW ] Processing packages now provide execution records with time and package filters, execution details, parameters, per-attempt durations, failure reasons, and retry support for failed workflow nodes.

### Optimizations

- [ OPTIMIZATION ] Improved natural-language intent recognition in the AI Assistant with on-demand system and field information, multi-turn queries, and error correction.
- [ OPTIMIZATION ] Full audit log exports in the AI Assistant can download directly, with automatic asynchronous fallback for large datasets, timeouts, and other limiting conditions.
- [ OPTIMIZATION ] BKBase synchronous queries support environment-specific query paths.
- [ OPTIMIZATION ] Added loading skeletons and empty states for strategy editing, execution details, and package details, and improved risk type selection and execution status display.
- [ OPTIMIZATION ] Collapsed sidebars now retain only icons, while pages with custom sidebars preserve their existing layout.
- [ OPTIMIZATION ] Column filters in Scene Risks and Pending My Confirmation remain synchronized with search conditions.
- [ OPTIMIZATION ] Re-entering the Tool Marketplace returns to its list while retaining open tools and usage counts; direct tool links still open the corresponding details.

### Fixed

- [ FIXED ] Fixed submission errors for ITSM V4 approval tickets containing option fields such as dropdowns and multi-selects.
