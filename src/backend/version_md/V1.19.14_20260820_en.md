## Version 1.19.14 Release Notes

### New Features

- [ NEW ] Scene access now supports self-service requests and approval-based authorization. Approved requests automatically grant scene management or usage access, and users can track request status.
- [ NEW ] Audit risk event search now supports filters on basic event information and event-detail fields, with fields grouped by type and ordered for easier selection.

### Fixed

- [ FIXED ] Fixed reports occasionally redirecting to the first report while report data was loading.
