## Version 1.19.17 Release Notes

### New Features

- [ NEW ] Scene Risks and All Risks support selecting risks across pages for batch processing, including manual closure, reassignment, processing packages, and marking or unmarking false positives. Standard operations support up to 500 risks; processing packages support up to 100.
- [ NEW ] The AI Assistant supports intelligent analysis and statistics for audit logs, with report listing, viewing, editing, exporting, and regeneration.

### Optimizations

- [ OPTIMIZATION ] Scene Risks now supports intelligent search, with improved search condition and time label interactions.
- [ OPTIMIZATION ] Processing package execution status now refreshes automatically in risk details.

### Fixed

- [ FIXED ] Fixed duplicate default-value tooltips in the visibility dialog for global tools under Platform Management.
- [ FIXED ] Fixed missing icons on some tool cards in the Tool Marketplace.
- [ FIXED ] Fixed an issue where changing an API tool parameter's frontend type could clear other parameter defaults, and corrected operation column overflow.
