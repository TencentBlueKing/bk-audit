## 怎么读明细

- **路径**：列代码中的 `action`，不是完整 URL。标为「单／多」时分别对应单租户／多租户；实际网关名、stage、ESB
  组件和自定义地址以部署配置为准。网关审批通常还需要上游登记的**资源名**，路径不能代替它。
- **身份**：列审计侧构造鉴权凭据的方式，不代表上游已经授权。「个人」保留当前用户身份；「应用」在鉴权字段使用应用凭据；「平台」由
  SDK 按平台鉴权配置构造；「租户管理员」是多租户基类额外替换的用户身份。「SDK 默认」需结合请求上下文判断，不能据此认定是个人态或纯应用态。是否额外透传
  Cookie 看具体封装；SDK 后台分支在启用平台鉴权时也可能使用旧平台凭据。
- **引用**：「代码」链接到至少一个静态调用或别名入口，可能受版本、功能开关或初始化步骤限制；「待确认」表示找到封装，但本次未确认调用点。不要把这类条目或所有分支路径一起提交授权。
- **去重**：同一网关的同方法同路径可能被多个 Resource 复用，例如 BKBase V4 同时有个人态和平台态，IAM
  系统详情也用于读取回调令牌。网关资源可以按实际登记去重，调用身份和租户仍要分开验收。

清单覆盖仓库后端的对外 HTTP 封装和已识别的直接调用。不含审计自身供前端调用的 API、浏览器跳转、第三方 SDK
内部且未核实的接口、数据库／Redis／消息队列等基础设施连接；IAM 入站回调单列是因为需要另行配置可达性和调用方身份。
