# 审计项目入口

先从当前目录或用户给定路径确认产品 Git 根目录，并核对项目 README 和 `src/frontend/package.json`。技能安装目录与产品 checkout 分别定位；读取当前目录适用的 AGENTS。

| 目标 | 当前产品内来源 | 产出 |
| --- | --- | --- |
| 探索项目、选择能力 | `agent/README.md` | 相关范围、技能与使用前提 |
| 新增、调整或删除协作能力 | `agent/architecture.md` | 按现有层级确定维护源、入链与验证范围 |

下层索引和技能按任务读取，不在入口重复完整清单。当前 checkout 缺少入口时使用该分支已有 README，不自动切分支、clone 或下载其他分支内容。缺少目录或能力时说明必要缺口。

返回选中的入口路径、用途和执行前提。安装、认证、业务修改、Git 写操作、部署和发布按具体任务授权执行。公开入口不接收内部资料、凭证或个人环境参数。
